# rougerRoll

一个掷骰子决定攻防伤害的 Boss 战 Web 小游戏。

## 运行方式

直接在浏览器中打开 `index.html`，或在项目目录执行：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 玩法

### 单人 PVE

- 玩家初始生命值为 20，Boss 初始生命值为 20。
- 点击“玩家行动”后会进入一回合：
  - 玩家先掷骰子，点数即对 Boss 造成的伤害。
  - 若 Boss 未被击败，Boss 会掷骰子反击，点数即对玩家造成的伤害。
- 每次 Boss 被击败后会立即重生并强化：
  - Boss 攻击骰上限 +1（D10 → D11 → D12...）。
  - Boss 最大生命值 +10，且会以满血重生。
- 玩家生命值降到 0 时战斗结束。
- 点击“重新开始”可重置战斗。


### PVP（新）

- 支持通过邀请链接进入同一个 PVP 房间（当前为本地演示模式）。
- 采用 BO3 规则：先赢 2 个小局的玩家获得整场胜利。
- 每个小局结束后会重置双方血量。
- 小局失败方会随机获得一种增益（攻击、减伤、吸血或生命上限提升），获胜方不变。
